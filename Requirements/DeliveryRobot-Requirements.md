# SV-V-LAB4
Autonomous Delivery Robot
| Req-ID | Description                                                                           | Priority |
| ------ | ------------------------------------------------------------------------------------- | -------- |
| R-01   | Robot shall remain idle until a delivery request is received.                         | High     |
| R-02   | Robot shall start navigation after receiving a delivery request.                      | High     |
| R-03   | Robot shall continuously monitor its surroundings while navigating.                   | High     |
| R-04   | Robot shall enter obstacle-avoidance mode when an obstacle is detected.               | High     |
| R-05   | Robot shall resume navigation after successfully avoiding an obstacle.                | High     |
| R-06   | Robot shall start the delivery process after reaching the destination.                | High     |
| R-07   | Robot shall return to the warehouse after successful delivery.                        | High     |
| R-08   | Robot shall return to the warehouse when the battery becomes critically low.          | High     |
| R-09   | Robot shall become idle after reaching the warehouse.                                 | Medium   |
| R-10   | Robot shall not enter delivery mode directly from idle or while avoiding an obstacle. | High     |
